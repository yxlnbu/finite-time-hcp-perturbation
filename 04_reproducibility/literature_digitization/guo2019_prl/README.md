# Guo et al. (2019) CP-Ti stress--temperature landmarks

Source: Y. Guo et al., “Temperature Rise Associated with Adiabatic Shear Band: Causality Clarified,” *Physical Review Letters* 122 (2019) 015503. DOI: 10.1103/PhysRevLett.122.015503.

- Material: commercial-purity Grade-II titanium.
- Source record: <https://doi.org/10.1103/PhysRevLett.122.015503>.

- Figure page was rendered locally at 300 dpi for traceable visual reading; the copyrighted page image is not redistributed in this repository.

The stress peak is an approximate manual read from Fig. 1 and is accompanied by a plotting-resolution interval. Event times are direct figure labels. Temperature intervals are transcribed from the article text. These landmarks are used only for an external timing-and-scale check. They are not fitted because the paper’s shear-compression specimen, texture, localization and damage differ from the homogeneous single-crystal simple-shear base path.
